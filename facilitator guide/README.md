# 🧑‍🏫 Facilitator Guide: Module 5 – Modern AI-Ready Tech Stack

## ⏱️ Duration
**30 minutes total**

---

## 👩‍💻 Audience
Software engineers building modern applications who want to future-proof their stack for seamless AI integration.

---

## 🎯 Learning Objectives
By the end of this module, learners will:
✅ Understand components of an AI-friendly tech stack.
✅ Identify integration points for AI in modern frameworks.
✅ Set up a starter project using recommended stack and document initial standards.
✅ Justify stack/tool choices for future AI adoption.

---

## 🗺️ Content Flow

### 1. **Kickoff & Overview (5 min)**
- Introduce the "AI-Ready Tech Stack" concept.
- Share the pain point: many frameworks claim to be AI-friendly, but few deliver.
- Emphasize why stack selection and setup standards (CLAUDE.md, scripts, modularity) are critical for AI-powered development.

---

### 2. **Demo & Guided Setup (8 min)**
- Walk through scaffolding a new project using **Next.js 15, Supabase, Shadcn/UI, Vercel**.
- Highlight:
  - Where to place initial documentation (starter CLAUDE.md file)
  - Example package.json scripts for linting, testing, type-checking
  - Modular file/folder structure for future AI integration

---

### 3. **Hands-On Learner Activity (12 min)**
- Learners:
  1. Scaffold their own starter project (via CLI or repo).
  2. Add at least one placeholder AI integration point (e.g., call to OpenAI, spot for LLM API, etc.).
  3. Draft a **starter CLAUDE.md** with basic rules/standards.
  4. Note and justify their stack/tool choices for AI readiness.
- Circulate to support setup and prompt stack/standards questions.

---

### 4. **Group Reflection & Comparison (5 min)**
- Group shares: Each learner names one integration point and one stack/tool decision.
- Discuss trade-offs (e.g., Supabase vs Firebase for AI data, Shadcn/UI for rapid UI prototyping).
- Optional: Compare two tech stack configs for AI fit.

---

## 📌 Key Talking Points
- **Intentional stack selection** beats shiny new tools.
- AI-ready projects require setup standards, not just framework choice.
- Documentation and modular structure are as important as code.

---

## 💬 Reflection Questions
- What made your stack selection “AI-friendly”?
- Where will you integrate your first AI tool?
- How does a CLAUDE.md or rules file help future developers (and AI agents)?
