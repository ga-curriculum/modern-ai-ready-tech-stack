# 📄 Participant Handout: Module 5 – Modern AI-Ready Tech Stack

---

## 🎯 Learning Objectives
By the end of this module, you will:
✅ Identify key frameworks/tools for an AI-friendly tech stack.
✅ Set up a project using the recommended stack.
✅ Draft your first CLAUDE.md with team standards.
✅ Explain your AI integration choices.

---

## 🏗️ Activity Steps

### 1. **Stack Up! (10 min)**
- Scaffold a new project using **Next.js 15** (or another recommended AI-ready framework).
- Add:
  - **Supabase** for your database & auth
  - **Shadcn/UI** for rapid UI building
  - **Vercel** (or similar) for deployment

---

### 2. **AI Integration Point (5 min)**
- In your project, add a **placeholder** for an AI integration:
  - (Example: A file for future LLM API calls, or a "Suggest" button in your UI)
  - Mark this spot clearly in code or notes.

---

### 3. **Starter DEVELOPMENT_RULES.md (10 min)**
- In your repo, create a basic **DEVELOPMENT_RULES.md** file.
- Include at least:
  - Your tech stack choices and *why* (1–2 sentences each)
  - At least two rules/standards for the project (see example below)
  - One area where AI will be integrated

**Example and Template:**
- [CLAUDE.md Example](./CLAUDE.md)
- [development_rules_template.md](development_rules_template.md)

---

### 4. **Share & Reflect (5 min)**
- Be ready to share your integration point and one tech choice with the group.
- Reflection:
  - What about this stack feels “future-proof” for AI?
  - What’s one challenge you faced setting up your stack?

---

## 📌 Why This Matters
By building with AI in mind from day one, you make your projects (and yourself) future-ready. Good stack selection and documentation help both humans and AI agents onboard faster, avoid tech debt, and deliver real value.

---

### **Reflection Questions**
- Where will you first use AI in your new project?
- What’s your “must-have” rule for every repo?
- How does documenting early help your team (or future self)?

---

## ✅ **Checklist for Success**
- [ ] Project scaffolded with Next.js, Supabase, Shadcn/UI
- [ ] Placeholder AI integration added
- [ ] Basic DEVELOPMENT_RULES.md drafted (with rationale, rules, and integration spot)
- [ ] Ready to explain your stack choices
